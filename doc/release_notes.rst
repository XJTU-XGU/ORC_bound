Release Notes
=============

0.2.2
-----

* Added Sphinx documentation under ``doc`` for Read the Docs builds.
* Updated documentation to the current residual-shell C++ API:
  ``residual_shell_based_orc_bound``.

  ``num_threads``, ``distance_cutoff``, and ``rbar_mode``.

-----

* Current package layout with ``src/orc_bound``.
* C++/OpenMP residual-shell kernel exposed through Python helpers.
* Weighted k-hop lazy random-walk measures with unweighted hop-distance
  transport ground metric.
